共享解码与确定性分析架构

目标是在保持 VCFtools 0.1.17 字节级输出兼容的前提下，让个体统计、窗口统计、LD/PCA、 格式写出和双 VCF 比较复用同一次 GT/DP 解码。

首选：AcceptedVariantBlock + DeterministicAnalysisLanes

Depth

Interface 只有 requirements、ordered consume 和 finalize；布局、背压和确定性藏在模块内部。

Leverage

一次 GT/DP 解码服务个体统计、群体统计、矩阵统计和格式写出。

Locality

所有“可交换整数归并”与“必须保持位点次序的浮点归并”规则集中管理。

候选二：OrderedSpanAnalysis

π、Tajima’s D 和 FST 使用有序位点贡献，处理跨 batch、重叠窗口和染色体切换。

  • 逐位点贡献在 worker 中计算。
  • 窗口浮点累加严格按原始位点顺序。
  • LD 改用 compact genotype store，按 left-site 分配 pair job，再按 left-site 顺序提交。

候选三：FilteredVariantStream + ArtifactWriter

双输入 diff 使用两个独立有界流做 sorted merge join；格式转换由有生命周期的 writer 复用 accepted block。

  • 双输入各自拥有 header、sample map、reader 和背压。
  • VCF/BCF 使用 HTS writer；样本主序格式使用 spool/transpose writer。
  • 临时文件、异常清理和最终计数统一封装。
