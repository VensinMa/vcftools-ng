# vcftools-ng v0.12.1 — Fused Site Statistics and Scalable Exact Recode

v0.12.1 expands shared direct site-statistics parsing and hardens the scalable
byte-exact recode pipeline.

## Highlights

- Fuses eligible `--freq`, `--freq2`, `--counts`, `--missing-site`,
  `--site-depth`, `--site-mean-depth`, and `--site-quality` outputs into one
  Plain/BGZF VCF scan.
- Adds bounded out-of-order worker backpressure while preserving exact input
  order at commit.
- Gives each recode compute worker its own HTSlib output header, fixing shared
  lazy-header mutation found by ASan/LSan without serializing VCF formatting.
- Keeps adaptive Plain byte ranges, indexed BGZF/BCF shards, automatic CSI,
  and no-index streaming fallbacks under one effective thread budget.
- Separates Original-compatible parameters from vcftools-ng-only extensions;
  Original VCFtools 0.1.17 does not have `--recode-vcf-gz`.
- Adds English and Simplified Chinese README files with visible language
  switching links.

## Exact full-data release gate

The 11,230,392-record, 23-chromosome, 412-sample dataset was filtered with
seven real-project parameters and recoded with all INFO fields. New Original
0.1.17 oracles were generated for BGZF VCF, Plain VCF, and BCF.

Seven input/index scenarios were run at 1/2/4/8/16/32 threads:

- 42/42 first-repeat candidate outputs were byte-identical;
- 42/42 candidate configurations were faster than Original;
- observed first-repeat speedup range: 4.11×–48.24×;
- automatic-CSI rows include fresh index construction;
- execution was strictly serial.

These are single-run release-gate results. Repeats 2–5 are intentionally
deferred and will be added to master after completion; no five-run mean is
claimed by this release note.

Automatic CSI was faster than no-index BGZF from two threads upward in this
workload. No-index BCF was faster than automatic CSI at every tested thread
count. Automatic indexing remains the default when a usable sidecar is
missing; `--no-auto-index` is the explicit override.

Full CPU, RSS, hashes, method, and continuation commands are in the
[v0.12.1 technical record](https://github.com/VensinMa/vcftools-ng/blob/master/docs/versions/v0.12.1.md).

## Install

```bash
curl -LO https://github.com/VensinMa/vcftools-ng/releases/download/v0.12.1/vcftools-ng-v0.12.1-linux-x86_64.tar.gz
curl -LO https://github.com/VensinMa/vcftools-ng/releases/download/v0.12.1/vcftools-ng-v0.12.1-linux-x86_64.tar.gz.sha256
sha256sum -c vcftools-ng-v0.12.1-linux-x86_64.tar.gz.sha256
tar -xzf vcftools-ng-v0.12.1-linux-x86_64.tar.gz
./vcftools-ng-v0.12.1-linux-x86_64/bin/vcftools-ng --version
```

The portable archive targets Linux x86_64 with glibc 2.17 or newer. It
includes vcftools-ng, bcftools, HTSlib, and required non-glibc runtime
libraries; no compiler, CMake, Conda, or system HTSlib is required.
