# vcftools-ng v0.12.3 — Comprehensive Colored Terminal Help

v0.12.3 turns `vcftools-ng -h` into a complete, readable terminal manual
without changing filtering, statistics, input, or output execution paths.

## Highlights

- Documents all 95 supported long options.
- Adds practical examples for statistics, exact filter/recode, direct BGZF
  VCF output, and region selection.
- Groups options by task and documents output suffixes, combination rules,
  compatibility boundaries, and adaptive input/index behavior.
- Uses restrained colors on interactive terminals while keeping pipes and
  redirected files clean.
- Supports the standard `NO_COLOR=1` opt-out and `CLICOLOR_FORCE=1` for
  explicitly colored output.
- Adds an automated help regression gate and portable-package color checks.

```bash
vcftools-ng --help
vcftools-ng --help > vcftools-ng-help.txt
NO_COLOR=1 vcftools-ng --help
CLICOLOR_FORCE=1 vcftools-ng --help
```

## Validation and performance evidence

Release CTest passed 5/5, ASan/UBSan CTest passed 5/5 with no finding, and
the portable archive passed clean CentOS 7 and Ubuntu 20.04 verification.
Detailed results are recorded in the
[v0.12.3 technical record](https://github.com/VensinMa/vcftools-ng/blob/master/docs/versions/v0.12.3.md).

No full-data benchmark was rerun: v0.12.3 changes only help, documentation,
and package validation. It inherits the hash-locked v0.12.2 matrix without
relabeling it:

- 11,230,392 records, 23 chromosomes, and 412 samples;
- four scenarios at 1/2/4/8/16/32 threads, five repeats each;
- 120/120 outputs byte-identical to VCFtools 0.1.17 goldens;
- mean speedup range: 5.97×–53.59×.

Full commands, hashes, CPU, RSS, and per-run results are in the
[v0.12.2 technical record](https://github.com/VensinMa/vcftools-ng/blob/master/docs/versions/v0.12.2.md).

## Install

```bash
curl -LO https://github.com/VensinMa/vcftools-ng/releases/download/v0.12.3/vcftools-ng-v0.12.3-linux-x86_64.tar.gz.sha256
sha256sum -c vcftools-ng-v0.12.3-linux-x86_64.tar.gz.sha256
tar -xzf vcftools-ng-v0.12.3-linux-x86_64.tar.gz
./vcftools-ng-v0.12.3-linux-x86_64/bin/vcftools-ng --version
```

The portable archive targets Linux x86_64 with glibc 2.17 or newer and keeps
vcftools-ng, bcftools, HTSlib, and required non-glibc runtime libraries
together. Archive SHA-256:
`7131735169972bd081854526b043f2da1c8e36aad137af3d42515a964a11fc72`.
