# vcftools-ng v0.12.4 — Standard Reproducible Run Logging

v0.12.4 closes the run-log compatibility and reproducibility gap while
preserving exact scientific output.

## Highlights

- Normal runs overwrite `PREFIX.log` by default.
- `--log-file FILE` selects a custom log path.
- `--no-log-file` disables the file while retaining terminal diagnostics.
- One central logger mirrors diagnostics to stderr and the log without
  contaminating VCF data written with `--recode --stdout`.
- Logs record the complete command, working directory, timestamps, input and
  output metadata, filters, sample/site counts, thread allocation, CPU, RSS,
  warnings, errors, and final status.
- Adaptive index decisions are explicit: detected TBI/CSI validation,
  build/use decision and reason, build threads/time, selected backend, and
  whether the index was used.
- Existing sidecars are validated and preserved even when full-file BCF
  recode deliberately selects the faster stream backend.
- Input/output path conflicts are rejected before opening the log, preventing
  accidental truncation.

## Validation and inherited performance

- Release CTest: 6/6 PASS.
- ASan/UBSan CTest: 6/6 PASS with no finding.
- Logging regression, including failure and path-safety cases: PASS.
- Logging-enabled real 2.3-million-record gate: 18/18 byte-identical outputs
  across BGZF VCF + TBI, Plain VCF, and BCF adaptive stream at
  1/2/4/8/16/32 threads.
- Observed development-gate speedup range: 4.90×–45.56× over locked Original
  timings.

v0.12.4 does not change scientific filtering, statistics, input scheduling,
or output bytes. With release-owner approval, it inherits the hash-locked
v0.12.2 full-data five-repeat matrix rather than rerunning it: 120/120 exact
outputs and 5.97×–53.59× mean speedup. These are inherited measurements, not
new v0.12.4 timings.

## Install

```bash
curl -LO https://github.com/VensinMa/vcftools-ng/releases/download/v0.12.4/vcftools-ng-v0.12.4-linux-x86_64.tar.gz
curl -LO https://github.com/VensinMa/vcftools-ng/releases/download/v0.12.4/vcftools-ng-v0.12.4-linux-x86_64.tar.gz.sha256
sha256sum -c vcftools-ng-v0.12.4-linux-x86_64.tar.gz.sha256
tar -xzf vcftools-ng-v0.12.4-linux-x86_64.tar.gz
./vcftools-ng-v0.12.4-linux-x86_64/bin/vcftools-ng --version
```

The portable archive targets Linux x86_64 with glibc 2.17 or newer and
bundles vcftools-ng, bcftools 1.23, HTSlib 1.23, and required non-glibc
runtime libraries. It passed clean CentOS 7 and Ubuntu 20.04 validation.
