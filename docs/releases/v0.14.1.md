# vcftools-ng v0.14.1 — Capability-Planned Exact Analytics

v0.14.1 turns the v0.13.2 development work into a fully qualified release. It
reduces unnecessary FORMAT decoding and post-scan memory work while preserving
the documented VCFtools 0.1.17 byte contract.

## Highlights

- One immutable `QueryPlan` selects required fields, the exact kernel, and a
  stable fallback reason before outputs are opened.
- Compatible filters, statistics, and recode share one record/sample decode;
  GT-only analyses avoid unused DP/GQ/FT field work.
- The production numeric/genotype filter set, FILTER/INFO/FT, site pi,
  no-index BGZF overlap, LD, exact PCA, and indexed BCF diff work from the
  unreleased v0.13.2 cycle are included.
- LD uses one contiguous bit-plane allocation and fixed 64-left-site ordered
  formatting blocks. PCA precomputes sample-major normalized dosage while
  retaining the exact per-cell accumulation order.
- Truncated/malformed input, records larger than 8 MiB, missing contig
  declarations, zero selected samples, NaN/Inf, numeric overflow, cancellation,
  and transactional rollback have directed regression coverage.
- Site-only raw VCF recode preserves legal polyploid GT text; commands that
  require genotype semantics reject ploidy above two transactionally.
- Automatic CPU selection intersects scheduler/affinity/cgroup/hardware
  limits and remains capped at 128 only when `--threads` is omitted.

## Exactness and performance qualification

- Fixed 23k gate: **45/45 PASS**.
- Odd-thread gate: **99/99 PASS**.
- Locked 230k LTO matrix: **216/216 PASS**.
- Final PGO Plain A/B: **168/168 PASS**.
- Final PGO indexed/no-index BGZF A/B: **96/96 PASS**.
- 2.3-million-record PGO differential: **PASS**.
- Full 11,230,392-record first-repeat release gate: **36/36 PASS** across
  BGZF+TBI, BGZF+automatic CSI, Plain VCF, and adaptive-stream BCF at
  `1/2/4/8/12/16/24/28/32` threads.

input/index and retained v0.12.1 Original golden by size and SHA-256. All
candidate outputs passed complete-file `cmp`; retained sites were always
5,425,725 of 11,230,392. Values below are single first-repeat wall seconds,

The automatic-CSI rows use bcftools 1.24 with HTSlib 1.24. The BCF full-file
workload deliberately streams even when CSI exists because that is the faster
validated policy for this workload. Follow-up adaptive repeats remain pending
and will not be mixed into this first-repeat table.

Detailed design, safety boundaries, rejected experiments, and raw-evidence
links are in the [v0.14.1 technical
record](https://github.com/VensinMa/vcftools-ng/blob/v0.14.1/docs/versions/v0.14.1.md).

## Install

```bash
curl -LO https://github.com/VensinMa/vcftools-ng/releases/download/v0.14.1/vcftools-ng-v0.14.1-linux-x86_64.tar.gz
curl -LO https://github.com/VensinMa/vcftools-ng/releases/download/v0.14.1/vcftools-ng-v0.14.1-linux-x86_64.tar.gz.sha256
sha256sum -c vcftools-ng-v0.14.1-linux-x86_64.tar.gz.sha256
tar -xzf vcftools-ng-v0.14.1-linux-x86_64.tar.gz
./vcftools-ng-v0.14.1-linux-x86_64/bin/vcftools-ng --version
```

The archive targets Linux x86_64 with glibc 2.17 or newer. It is built on the
manylinux2014/CentOS 7 baseline and verified in clean CentOS 7 and Ubuntu
20.04 containers. `bin` contains only `vcftools-ng`; private bcftools 1.24,
HTSlib 1.24, and non-glibc runtime libraries remain under `libexec`/`lib`.
