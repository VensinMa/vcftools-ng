# vcftools-ng v0.11.1

Status: **complete for automatic CSI construction on local BGZF VCF and BCF
inputs**.

## Behavior

Before selecting an input backend, automatic mode checks for `.csi` and
`.tbi` sidecars. For a local BGZF VCF or BCF without either index,
vcftools-ng invokes:

```text
bcftools index --csi --threads EFFECTIVE_THREADS --output TEMP INPUT
```

`EFFECTIVE_THREADS` is the value passed with `--threads`; when it is omitted,
the existing scheduler, CPU-affinity, or hardware-concurrency detector
provides the value. The temporary CSI is written beside the input and
atomically published as `INPUT.csi`, without replacing an index created by
another process, only after bcftools exits successfully.

An advisory lock on the input serializes simultaneous vcftools-ng index
builders. A process that waited for another builder rechecks the sidecars and
uses the completed index. Failed temporary files are removed.

Defaults and controls:

- automatic indexing is enabled for `--input-backend auto` and `indexed`;
- `--input-backend stream` never creates an index;
- `--no-auto-index` disables the feature;
- `--bcftools FILE` selects a non-default bcftools executable;
- automatic mode reports a warning and falls back to the ordered stream if
  bcftools cannot run or indexing fails;
- forced `--input-backend indexed` reports the indexing failure and exits.

Plain VCF, ordinary gzip, remote inputs, diff streams, and inputs that already
have TBI/CSI are not modified.

## Validation

The input-backend regression covers:

- explicit four-thread CSI construction for BGZF VCF and BCF;
- automatic three-thread selection from `SLURM_CPUS_PER_TASK`;
- `--no-auto-index`;
- two concurrent builders for one input;
- missing-bcftools fallback in auto mode;
- missing-bcftools failure in forced indexed mode;
- removal of temporary index files;
- byte-identical counts across stream, Plain, pre-indexed, and auto-indexed
  backends.

The full cumulative `ctest` run passed 2/2 tests: the input-backend test took
5.74 seconds and the cumulative differential compatibility test took 107.09
seconds. After the final no-replace publication refinement, the input-backend
test was rerun and passed in 5.76 seconds.

The real-subset gate used 2,300,000 records and started each run without an
index:

| Engine | Threads | Wall seconds | Speedup | Exact |
|---|---:|---:|---:|---|
| VCFtools 0.1.17, no index | 1 | 68.22 | 1.00× | oracle |
| vcftools-ng, build CSI + counts | 8 | 27.84 | 2.45× | PASS |
| vcftools-ng, build CSI + counts | 16 | 22.69 | 3.01× | PASS |

The wall times include CSI construction. Both outputs have the same SHA-256
as the saved original result. Each generated CSI was 99,846 bytes.
