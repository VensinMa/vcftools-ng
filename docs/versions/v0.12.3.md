# vcftools-ng v0.12.3

Subtitle: **Comprehensive Colored Terminal Help**.

Status: **qualified for release**.

## Scope

v0.12.3 replaces the former compact `-h` output with a complete terminal
reference:

- 95/95 supported long options are documented;
- quick examples cover statistics, exact filtering/recode, direct BGZF VCF,
  and region selection;
- options are grouped by input, output, filtering, comparison, and execution
  purpose;
- output suffixes, important combination rules, compatibility boundaries,
  and adaptive input/index behavior are stated directly in the help;
- `-h` and `--help` are identical and write no diagnostics to stderr;
- interactive terminals use restrained ANSI colors, redirected or piped help
  remains plain, `NO_COLOR=1` disables colors, and `CLICOLOR_FORCE=1` enables
  them for tooling and tests.

The filter, statistics, input, scheduler, compression, and output execution
paths are unchanged from v0.12.2.

## Validation

The dedicated `help_output` regression gate verifies:

- every documented heading and all supported options;
- a maximum plain-text width of 100 columns;
- identical `-h` and `--help` output;
- no ANSI escapes when output is redirected or `NO_COLOR` is set;
- colored output whose ANSI-stripped bytes exactly equal plain output.

Final qualification results:

- Release CTest: 5/5 passed in 128.19 seconds;
- ASan/UBSan CTest: 5/5 passed in 299.59 seconds with no sanitizer finding;
- dedicated help gate: PASS in both builds.

## Inherited exactness and performance evidence

No full-data performance matrix was rerun because v0.12.3 changes no measured
execution path. It inherits the hash-locked v0.12.2 release evidence:

- 11,230,392 input records across 23 chromosomes and 412 samples;
- four input scenarios;
- 1/2/4/8/16/32 threads;
- five strictly serial repeats per configuration;
- 120/120 outputs byte-identical to retained VCFtools 0.1.17 goldens;
- observed mean speedup range: 5.97×–53.59×.

The original measurements, input and oracle hashes, commands, CPU, RSS, and
per-run results remain in:

These values are explicitly labeled inherited and are not represented as
