# vcftools-ng v0.12.4

Subtitle: **Standard Reproducible Run Logging**.

Status: **qualified for release**.

## Scope

v0.12.4 closes the run-log compatibility and reproducibility gap:

- normal runs overwrite `PREFIX.log` by default;
- `--log-file FILE` selects a custom path;
- `--no-log-file` disables only the file while retaining stderr;
- one central logger sends identical diagnostics to stderr and the file;
- `--recode --stdout` keeps VCF bytes isolated on stdout;
- a log-creation failure stops the run before scientific outputs are opened;
- input/output path conflicts are rejected before the log is opened, including
  equivalent and symlink-resolved paths;
- runtime and argument failures retain the partial log and final failed status
  whenever a log destination can be resolved.

The text schema is identified by:

```text
Log format: vcftools-ng-text-v1
```

## Recorded evidence

Each log includes:

- version, complete shell-quoted command, working directory, and timestamps;
- input path, format, byte size, and storage type;
- index policy, every detected valid sidecar, validation, build/use decision,
  reason, build threads/time, selected backend, and whether an index was used;
- requested/effective threads, input/HTSlib/compute allocation, shards, batch
  size, and scheduler;
- requested outputs and filters;
- selected samples, total/kept sites, output paths and byte sizes;
- wall, user CPU, system CPU, average CPU, peak RSS, warnings/errors, final
  status, and end time.

An existing valid CSI/TBI is validated and reported even when a full-file BCF
recode selects the faster stream backend. Being unused does not make an index
invalid; existing sidecars remain protected from deletion and overwrite.

## Inherited full-data performance evidence

The scientific filtering, statistics, input scheduling, and output bytes are
unchanged from the v0.12.2/v0.12.3 runtime. With explicit release-owner
approval, v0.12.4 therefore inherits the hash-locked v0.12.2 full-data matrix
instead of repeating it:

- 11,230,392 records, 23 chromosomes, and 412 samples;
- four representative input scenarios;
- 1/2/4/8/16/32 threads and five serial repeats;
- 120/120 outputs byte-identical to retained VCFtools 0.1.17 goldens;
- observed mean speedup range: 5.97×–53.59×.

The v0.12.4 logging-enabled three-scenario gate above is new evidence and is
not presented as a replacement full-data matrix.
