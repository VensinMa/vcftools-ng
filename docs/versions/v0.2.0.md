# vcftools-ng v0.2.0

## Scope

Added common site/genotype filtering and exact VCF recoding. Genotype filters
mask only GT; all other FORMAT values remain unchanged.

## Parameters added

- Outputs: `--recode`, `--recode-INFO-all`
- Site filters: `--min-alleles`, `--max-alleles`, `--remove-indels`,
  `--keep-only-indels`, `--minQ`, `--min-meanDP`, `--max-meanDP`,
  `--max-missing`, `--max-missing-count`, `--maf`, `--max-maf`
- Genotype filters: `--minGQ`, `--minDP`, `--maxDP`

## Validation

- Fixture: complete 2,300,000-record real subset.
- Combined filter retained 129,855 records.
- Five statistics, default recode, and INFO-all recode were byte-identical.
- INFO-all golden size: approximately 1.4 GB.

## Benchmark

| Workload | Original | 8 threads | 16 threads | Exact |
|---|---:|---:|---:|---|
| Filtered INFO-all recode | 156.14 s | 5.42 s | 4.58 s | PASS |

Speedup: 28.81× and 34.09×. The combined five-statistics run at 16 threads
took 4.68 seconds; a matching filtered original aggregate was not separately
recorded.
