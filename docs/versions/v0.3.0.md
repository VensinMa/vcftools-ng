# vcftools-ng v0.3.0

## Scope

Added chromosome, range, and position-list selection before genotype/depth
decoding. A single-chromosome BCF query uses its CSI index.

## Parameters added

- `--chr`, `--not-chr`
- `--from-bp`, `--to-bp`
- `--positions`, `--exclude-positions`

## Validation and benchmark

| Workload | Retained | Original | 8 threads | 16 threads | Exact |
|---|---:|---:|---:|---:|---|
| positions + exclude + not-chr | 16 | 39.80 s | 3.39 s | 未记录 | PASS |
| indexed `chr7:1-2000000` | 29,816 | 48.88 s | 0.24 s | 0.19 s | PASS |

The indexed speedups were 203.67× and 257.26×. Complete recoded VCF files,
including headers and record order, were compared byte for byte.
