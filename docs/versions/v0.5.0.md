# vcftools-ng v0.5.0

## Scope

Added minor-allele count filtering and the exact VCFtools HWE implementation.

## Parameters added

- `--mac`, `--max-mac`
- `--hwe`

MAC is the minimum count across all alleles, including REF. HWE uses only
fully called diploid genotypes remaining after sample and genotype filters
and ports the original Wigginton recurrence.

## Validation and benchmark

- Fixture: complete 2,300,000-record subset.
- Workload: 17 selected samples, common filters,
  `--mac 4 --max-mac 12 --hwe 0.001`.
- Retained: 57,595 sites.

| Original | 8 threads | 16 threads | Speedup | Exact |

| 104.85 s | 4.01 s | 3.64 s | 26.15× / 28.80× | PASS |
