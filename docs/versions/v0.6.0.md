# vcftools-ng v0.6.0

## Scope

Added BED inclusion/exclusion with chromosome-indexed interval lookup before
genotype/depth decoding.

## Parameters added

- `--bed`
- `--exclude-bed`

The implementation retains the original 0-based BED rule and variant span
based on the longest REF/ALT allele.

## Validation and benchmark

| Workload | Retained | Original | 8 threads | 16 threads | Exact |
|---|---:|---:|---:|---:|---|
| BED include counts | 79,437 | 40.95 s | 3.50 s | 3.39 s | PASS |
| BED exclude counts | 2,220,563 | 66.29 s | 未记录 | 4.13 s | PASS |

Include speedup: 11.70× and 12.08×. Both complementary output files were
compared completely.
