# vcftools-ng v0.7.0

## Scope

Added ordered thinning after all preceding filters.

## Parameters added

- `--thin`

VCFtools bases each decision on the previous site that survived every earlier
filter. Independent filtering remains parallel, while the thinning state is
updated only during ordered commit.

## Validation and benchmark

- Workload: BED selection plus `--thin 10000`.
- Retained: 433 of 2,300,000 sites.

| Original | 8 threads | 16 threads | Speedup | Exact |
|---:|---:|---:|---:|---|
| 39.94 s | 3.49 s | 3.36 s | 11.44× / 11.89× | PASS |
