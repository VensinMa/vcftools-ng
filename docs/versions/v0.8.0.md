# vcftools-ng v0.8.0

## Scope

Added lower/upper non-reference allele-frequency and allele-count filtering
for all-ALT and any-ALT modes.

## Parameters added

- `--non-ref-af`, `--max-non-ref-af`
- `--non-ref-af-any`, `--max-non-ref-af-any`
- `--non-ref-ac`, `--max-non-ref-ac`
- `--non-ref-ac-any`, `--max-non-ref-ac-any`

Exact mode preserves the VCFtools 0.1.17 quirk where `--non-ref-af-any` alone
does not filter.

## Validation and benchmark

- Workload: all eight parameters with BED and 17 selected samples.
- Retained: 22,168 sites.
- A separate full-subset test covers the `--non-ref-af-any` quirk.
