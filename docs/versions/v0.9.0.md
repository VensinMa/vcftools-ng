# vcftools-ng v0.9.0

## Scope

Added site FILTER, INFO Flag, and genotype FT compatibility and replaced the
batch-barrier scheduler with a genuinely overlapped, bounded pipeline.

## Parameters added

- Site: `--keep-filtered`, `--remove-filtered`,
  `--remove-filtered-all`, `--keep-INFO`, `--remove-INFO`
- Genotype: `--remove-filtered-geno`,
  `--remove-filtered-geno-all`

## Exact semantics

- Missing, PASS, single, multiple, and order-sensitive FT flags are covered.
- `PASS;LowDP` and `LowDP;PASS` retain original branch behavior.
- Recode sorts multiple site FILTER names as the original VCF parser does.
- FT filtering masks only GT; FT and every other FORMAT value remain.

## Validation

- Main gate: complete 2,300,000-record real subset.
- Flag gate: 23,000 real records with deterministic annotations and all 412
  samples.
- Full CTest: 50.58 seconds, 1/1 passed, zero failures.
- All golden SHA-256 checks passed.

## Pipeline

Reader, persistent compute workers, and ordered committer overlap work on at
most three batches. Default batch size is 2,048; worker scratch and genotype
filter storage are reused.

## Benchmark

| Workload | Original | 8 threads | 16 threads | Speedup | Exact |
|---|---:|---:|---:|---:|---|
| Sample selection + six outputs | 623.49 s | 3.11 s | 3.13 s | 200.48× / 199.20× | PASS |
| 1.4 GB filtered INFO-all recode | 156.14 s | 3.37 s | 3.37 s | 46.33× / 46.33× | PASS |

Latest raw timing:

- Six outputs: 8t CPU 679%, RSS 26.7 MiB; 16t CPU 698%, RSS 24.8 MiB.
- Recode: 8t CPU 956%, RSS 54.2 MiB; 16t CPU 1002%, RSS 49.8 MiB.

Compared with the removed barrier scheduler, the pipeline improved the two
workloads by 16.8–41.1%.
